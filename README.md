# Micro Solar DC Wiki

Plain-language guides for setting up a small off-grid solar power system safely: plan it, pick
the parts, wire it, keep it running. Built with [Starlight](https://starlight.astro.build) and
hosted on Cloudflare.

## Contribute
Pages are Markdown files in `src/content/docs/`. Start from `templates/page.md`. Every number or
safety rule needs a source listed in the page's frontmatter. Rules for writers and AI agents:
[AGENTS.md](AGENTS.md).

```
npm install
npm run dev     # preview at http://localhost:4321
npm run build   # checks page rules and links, writes dist/
```
